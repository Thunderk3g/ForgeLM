# GPU Sharing Implementation for LLM Forge Platform - Complete Integration Guide

## MISSION
You are tasked with implementing a production-ready GPU sharing solution for the LLM Forge fine-tuning platform. This platform has THREE GPU-dependent microservices that currently cause container restarts and fine-tuning failures due to improper GPU resource management. Your mission is to diagnose, implement, and verify a complete solution that ensures all three services function reliably without conflicts.

**DO NOT STOP until all three microservices are operational, tested, and verified to work correctly with GPU sharing.**

---

## CURRENT ARCHITECTURE ANALYSIS

### Existing Microservices
The platform has the following GPU-dependent services:

1. **Training Service** (Port 8001)
   - Dockerfile: `training_service.dockerfile`
   - Base: `llmforge-ml-base:latest`
   - Purpose: LLM fine-tuning operations
   - Resource needs: HIGH GPU memory, compute-intensive

2. **Chat Comparison Service** (Port 8002)
   - Dockerfile: `chat_comparison_service.dockerfile`
   - Base: `llmforge-ml-base:latest`
   - Purpose: Fast inference for model comparisons
   - Resource needs: MODERATE GPU memory, inference-optimized

3. **Model Management Service** (Port 8005)
   - Dockerfile: `model_management_service.dockerfile`
   - Base: `llmforge-ml-base:latest`
   - Purpose: Model loading, inference, management
   - Resource needs: MODERATE GPU memory

### Current Issues
- Containers restart unexpectedly during fine-tuning
- GPU memory contention between services
- No resource isolation or QoS guarantees
- Potential OOM (Out of Memory) kills
- Lack of proper GPU allocation strategy

3. **Update Service Code for Graceful GPU Memory Management**
   
   Create `src/common/gpu_manager.py`:
   ```python
   """
   GPU Memory Management Utilities for LLM Forge
   """
   import torch
   import gc
   import logging
   from functools import wraps
   
   logger = logging.getLogger(__name__)
   
   def clear_gpu_memory():
       """Clear GPU memory cache"""
       if torch.cuda.is_available():
           torch.cuda.empty_cache()
           gc.collect()
           logger.info("GPU memory cache cleared")
   
   def gpu_memory_cleanup(func):
       """Decorator to cleanup GPU memory after function execution"""
       @wraps(func)
       def wrapper(*args, **kwargs):
           try:
               result = func(*args, **kwargs)
               return result
           finally:
               clear_gpu_memory()
       return wrapper
   
   def get_gpu_memory_info():
       """Get current GPU memory usage"""
       if not torch.cuda.is_available():
           return None
       
       device = torch.cuda.current_device()
       allocated = torch.cuda.memory_allocated(device) / 1024**3  # GB
       reserved = torch.cuda.memory_reserved(device) / 1024**3    # GB
       total = torch.cuda.get_device_properties(device).total_memory / 1024**3  # GB
       
       return {
           "device": device,
           "allocated_gb": round(allocated, 2),
           "reserved_gb": round(reserved, 2),
           "total_gb": round(total, 2),
           "free_gb": round(total - allocated, 2)
       }
   
   def set_gpu_memory_fraction(fraction: float = 0.9):
       """Set maximum GPU memory fraction"""
       if torch.cuda.is_available():
           torch.cuda.set_per_process_memory_fraction(fraction)
           logger.info(f"Set GPU memory fraction to {fraction}")
   
   class GPUMemoryMonitor:
       """Context manager for monitoring GPU memory usage"""
       def __init__(self, name: str = "Operation"):
           self.name = name
           self.start_mem = None
       
       def __enter__(self):
           if torch.cuda.is_available():
               clear_gpu_memory()
               self.start_mem = torch.cuda.memory_allocated() / 1024**3
               logger.info(f"{self.name} - Starting GPU memory: {self.start_mem:.2f} GB")
           return self
       
       def __exit__(self, exc_type, exc_val, exc_tb):
           if torch.cuda.is_available():
               end_mem = torch.cuda.memory_allocated() / 1024**3
               delta = end_mem - self.start_mem if self.start_mem else 0
               logger.info(f"{self.name} - Ending GPU memory: {end_mem:.2f} GB (Δ {delta:+.2f} GB)")
               clear_gpu_memory()
   ```

2. **Create Load Test**
   Create `tests/load_test_gpu.py`:
   ```python
   """
   Load testing for GPU services
   """
   import concurrent.futures
   import requests
   import time
   import statistics
   
   def send_request(service_url, request_num):
       """Send a single request"""
       start = time.time()
       try:
           response = requests.post(
               f"{service_url}/inference",
               json={"text": f"Test request {request_num}"},
               timeout=60
           )
           elapsed = time.time() - start
           return {
               "success": response.status_code == 200,
               "time": elapsed,
               "request": request_num
           }
       except Exception as e:
           return {
               "success": False,
               "time": time.time() - start,
               "error": str(e),
               "request": request_num
           }
   
   def load_test(service_name, service_url, num_requests=10, concurrency=3):
       """Run load test on a service"""
       print(f"\n=== Load Testing {service_name} ===")
       print(f"Requests: {num_requests}, Concurrency: {concurrency}")
       
       results = []
       with concurrent.futures.ThreadPoolExecutor(max_workers=concurrency) as executor:
           futures = [
               executor.submit(send_request, service_url, i)
               for i in range(num_requests)
           ]
           
           for future in concurrent.futures.as_completed(futures):
               result = future.result()
               results.append(result)
               status = "✓" if result["success"] else "✗"
               print(f"{status} Request {result['request']}: {result['time']:.2f}s")
       
       # Statistics
       successful = [r for r in results if r["success"]]
       if successful:
           times = [r["time"] for r in successful]
           print(f"\nSuccess Rate: {len(successful)}/{num_requests}")
           print(f"Avg Time: {statistics.mean(times):.2f}s")
           print(f"Min Time: {min(times):.2f}s")
           print(f"Max Time: {max(times):.2f}s")
       
       return len(successful) == num_requests
   
   if __name__ == "__main__":
       services = {
           "Training": "http://localhost:8001",
           "Chat Comparison": "http://localhost:8002",
           "Model Management": "http://localhost:8005"
       }
       
       all_passed = True
       for name, url in services.items():
           passed = load_test(name, url, num_requests=5, concurrency=2)
           all_passed = all_passed and passed
       
       exit(0 if all_passed else 1)
   ```

   ```python
   """
   Detect GPU memory leaks
   """
   import subprocess
   import time
   import requests
   
   def get_gpu_memory():
       """Get current GPU memory usage"""
       result = subprocess.run(
           ["nvidia-smi", "--query-gpu=memory.used", "--format=csv,noheader,nounits"],
           capture_output=True,
           text=True
       )
       return int(result.stdout.strip())
   
   def test_memory_leak(service_url, num_iterations=100):
       """Test for memory leaks"""
       print(f"Testing memory leak for {service_url}")
       
       memory_readings = []
       
       for i in range(num_iterations):
           # Get memory before
           mem_before = get_gpu_memory()
           
           # Make request
           try:
               requests.post(
                   f"{service_url}/inference",
                   json={"text": f"Test {i}"},
                   timeout=30
               )
           except Exception as e:
               print(f"Request {i} failed: {e}")
           
           time.sleep(1)
           
           # Get memory after
           mem_after = get_gpu_memory()
           
           memory_readings.append(mem_after)
           
           if i % 10 == 0:
               print(f"Iteration {i}: {mem_after}MB")
       
       # Analyze trend
       start_mem = sum(memory_readings[:10]) / 10
       end_mem = sum(memory_readings[-10:]) / 10
       
       leak_threshold = 100  # MB
       
       if end_mem - start_mem > leak_threshold:
           print(f"✗ MEMORY LEAK DETECTED: {end_mem - start_mem:.2f}MB increase")
           return False
       else:
           print(f"✓ No memory leak detected ({end_mem - start_mem:.2f}MB change)")
           return True
   
   if __name__ == "__main__":
       services = {
           "Training": "http://localhost:8001",
           "Chat Comparison": "http://localhost:8002",
           "Model Management": "http://localhost:8005"
       }
       
       all_passed = True
       for name, url in services.items():
           print(f"\n=== Testing {name} ===")
           passed = test_memory_leak(url, num_iterations=50)
           all_passed = all_passed and passed
       
       exit(0 if all_passed else 1)
   ```

## TROUBLESHOOTING GUIDE

### Issue: Container keeps restarting
**Diagnosis:**
```bash
docker logs llmforge-training --tail 100
docker inspect llmforge-training
```

**Possible causes:**
1. OOM kill - Check `dmesg | grep -i oom`
2. GPU not accessible - Verify NVIDIA runtime
3. Port conflicts - Check `netstat -tulpn`

**Solutions:**
- Increase memory limits in docker-compose.yml
- Verify GPU allocation with `nvidia-smi`
- Check for port conflicts and adjust

### Issue: CUDA out of memory
**Diagnosis:**
```bash
nvidia-smi
docker exec llmforge-training python -c "import torch; print(torch.cuda.memory_summary())"
```

**Solutions:**
- Reduce batch sizes in training config
- Implement gradient accumulation
- Enable memory-efficient attention
- Clear GPU cache between operations

### Issue: Services can't see GPU
**Diagnosis:**
```bash
docker run --rm --gpus all nvidia/cuda:12.0-base nvidia-smi
docker exec llmforge-training nvidia-smi
```

**Solutions:**
- Verify NVIDIA Container Toolkit installation
- Check `/etc/docker/daemon.json` for nvidia runtime
- Restart Docker daemon: `sudo systemctl restart docker`

### Issue: Poor performance/high latency
**Diagnosis:**
```bash
./scripts/monitor_gpu.sh
docker stats --no-stream
```

**Solutions:**
- Check GPU utilization (should be >70% during inference)
- Verify batch sizes are optimal
- Check for CPU bottlenecks
- Ensure proper MPS/MIG configuration
